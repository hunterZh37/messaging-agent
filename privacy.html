Celeste — Privacy Policy

Last updated 9 October 2026

Celeste is a personal mail client. It is built and run by one person, Hunter Zhang, for their own mailboxes, and it runs on their own computer. It is not a service, it has no other users, and it has no accounts to sign up for.

This policy describes what Celeste does with data from Google accounts, because Celeste signs in to Gmail using Google OAuth.

What Celeste accesses

With the operator's permission, Celeste uses the Gmail API to read their mail, mark it read, move it between folders including Trash, and send mail they have written. It also reads their email address so it can tell their own mailboxes apart.

Celeste accesses only the mailboxes the operator has explicitly connected, and only their own.

Where that data goes

  • It is stored on the operator's own computer, in a SQLite database file in their home folder. It is not uploaded to any server belonging to Celeste, because there is no such server.
  • Some of it is processed on that same computer by local models running under Ollama, which sort mail and build the search index. Nothing sent to those models leaves the machine.
  • Some of it is sent to Anthropic's API — but only when the operator asks Celeste a question about their mail, or asks it to draft a reply. In those cases the text of the relevant messages is sent to Anthropic so the model can answer or write. This does not happen in the background, and it does not happen to mail the operator has not asked about.

What Celeste does not do

  • It does not sell, rent, or share data with anyone.
  • It does not use mail for advertising, profiling, or market research.
  • It has no analytics, no telemetry, and no crash reporting.
  • It does not use Google user data to train any machine learning model.
  • It does not transfer Google user data to anyone except as described above.

Google API Services User Data Policy

Celeste's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Mail Celeste has synced stays in the local database until the operator deletes it. Because that database is a file on their own computer, deleting it deletes everything Celeste holds.

Access can be withdrawn at any time from myaccount.google.com/permissions, which immediately stops Celeste from reading anything further.
